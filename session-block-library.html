How a session is built

Seventy-seven of this team's own U10/U11 sessions (source: TSheehan) across two seasons — U10 (last year, February–November) and U11 (this year, February–August) — plus this club's own U6, U7, U8 and U9 weekly session archives (228 drills, extracted from over 115 further session plans), plus two external reference libraries: U8 drills (source: Monaghan Drills) and a Nursery Programme for ages 4–8 (source: GAA Fun Do Nursery Programme, 2007). All broken into component blocks and grouped by what each block is actually training.

Warm-up10–20
Passing~10
Tackling~10
Attack~10
Game10–15

Total session: 50–65 min (Feb sessions and the S52 wall-ball session run longer). The 5-part skeleton holds across both age groups and both seasons — only the drill filling each slot, and how much technique-coaching gets folded in, changes.

Venue and squad progression. U10 season (last year): grass pitches July–October, closing out indoors/wall-based in November as evenings draw in. U11 season (this year): indoor Feb → astro early March → grass pitches from mid-March. Nice bookend — both seasons start or end with the same indoor/wall format when outdoor conditions don't allow full pitch use.

U10 also runs a handful of combined-code evenings ("Hurling Football" in one session, S32/S34/S51) — something the U11 season never does; U11 always keeps hurling and football in separate weeks.

Where the drills come from
  • Cúl Camp Hurling Resource (Kellogg’s GAA Cúl Camps / Leinster GAA) — the official five-day camp programme for three age bands (6–7, 8–10 and 11–13), each day built from six activities (warm-up, skill games and team games/small-sided games), plus 8 standalone Wall Ball Sessions drills. 98 entries total. Hurling-only; every entry is tagged age:"both" since the source doesn't distinguish finer ages within each band. The 11–13 band and Wall Ball Sessions feed the U10/U11/U12 mode below, the 8–10 band feeds U8/U9, and the 6–7 band feeds U6/U7.
  • Coaching Drills (Philip Kerr, 2004) — a football coaching manual aimed at older/more advanced players: warm-ups and speed/agility work, passing and evasion drills, tackling technique, shooting drills, and tactical small-sided games. 30 entries, 27 with a layout diagram traced from the manual's own hand-drawn diagrams. Football-only; credited to Philip Kerr, 2004 (pkerrme@btinternet.com). Feeds the 13-18 mode below.
  • Football & Hurling Coaching Classes (GAA Fun Do, 2007) — the official GAA Fun Do resource covering 27 technique-based skills taught at U-8, U-10 and U-12 (catching/striking, kicking/passing, ball-carrying, tackling and evasion), each broken into Practise the Technique drills and Develop the Skill fun/modified games. 124 football + 141 hurling entries. Credited to GAA National Games Development Committee. U-8 entries also feed U8/U9 below; U-10/U-12 feed U10/U11/U12.
  • U6–U9 Sessions (Club Archive) — drills extracted from this club's own weekly session plans, also written by TSheehan. Duplicates across weeks are merged into one entry. Feeds the U6/U7 and U8/U9 modes below.

Everything else in the live library (the bulk of U10/U11/U12 and the U8/U9 "Monaghan Drills" set) is this team's own session records, as logged in the Data Notes and footer below.

Data notes

Small inconsistencies spotted while going through the source documents — flagging in case the originals get cleaned up.

  • S28 and S29 (U11) headed "Hurling" but contain football drills (kick-passing, point-scoring off a kick) — looks like a copy-paste from the football template.
  • Date banners repeat: U11 S1's banner reads "Feb 14th" against a filename of Feb 6th; U11 S28's reads "June 12th" (same as S27); U11 S16's reads "April 8th" (same as S14); U10 S34's reads "July 23rd" (same as S32); U10 S51's reads "Oct 22nd" (same as S50, which is actually Oct 22 — so S51 should likely read Oct 24).
  • U11 S18's closing "Hurling Game Setup" block isn't actually an anomaly — it's the same Team Shape & Positioning walkthrough that also appears at U11 S9, just under a different label.
  • U10 S22's date banner also reads "May 14th" — identical to S20's, despite the filename giving S22 as May 23rd.
  • U10 S28's attendance line reads "1 Attending approx" against a full two-team sheet of ~15 names — almost certainly a typo for a number closer to 14–15.
  • Two unrelated drills share the name "Around the Square": the hurling pressing/keep-away version (U11 S16) and a football 1v1 attack-the-defender version (U10 S14, S16). Worth renaming one in the source files to avoid confusion.
  • In the Monaghan Drills U8 pack, "Session 11" appears twice with entirely different content (an incomplete "Kicking to Space" version, then a full version reusing Session 1's warm-up and stations) — likely a document-assembly duplication in the source PDF rather than two genuine sessions.
  • Session numbering overlaps between the two age-group sequences — both have sessions numbered in the 30s–40s (e.g. "Session 36" exists in both U10 and U11). This library disambiguates U10 entries with a "U10" prefix; worth doing the same in the source filenames if the two ever get merged into one folder.
  • U6–U9 club archive entries (added from Coaching.zip) were extracted automatically: a script pulled out bold, timed section headers from each week's document and merged repeats of the same named drill/game across weeks into one entry. Header wording is often generic ("Football", "Skill 1", "Hurling & Football") where a session didn't name its drill distinctly — those entries are still included since the description body is genuine content, just under a plain label. Not manually reviewed line-by-line the way the U10/U11 library was, so expect some rough edges (an odd merge, a mis-tagged code, a stray coaching cue that isn't really a standalone drill).
  • U6–U9 authorship: confirmed by the club (11 Oct 2026) as also written by Tomas Sheehan (TSheehan).
  • U10 S31's filename reads "July 16th" but its own date banner reads "June 25th" — same date-banner-vs-filename mismatch pattern as the other anomalies above; filed under S31 (its filename position) here.
  • The Monaghan Drills U8 reference library actually has 45 drills, not the 34 the footer used to say — corrected below.
  • The GAA Fun Do Football and Hurling Coaching Classes resources (2007) were extracted from genuinely awkward two-column PDFs — a plain text extraction interleaved side-by-side drill boxes into nonsense. Entries were rebuilt with a column-aware parser (page-image reconstruction as a fallback for pages that still garbled), then grouped by age (U-8/U-10/U-12) and skill and lightly deduplicated. Not reviewed line-by-line against the source PDFs, so treat this batch like the U6–U9 club archive: generally trustworthy, occasional rough edges (a stray word bled in from a neighbouring box, a description that trails into the next drill's intro line).
